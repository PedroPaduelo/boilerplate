# 08 — Elevação, bordas e z-index

Catálogo de **sombras, raios, bordas, opacidades e camadas** efetivamente aplicados hoje no frontend
do AuditorIA.

Regras desta página:

- Valor sempre **bruto** (`0 8px 16px 0 rgba(145 158 171 / 0.16)`, `8px`, `1px`, `0.48`, `1101`).
  A referência simbólica da biblioteca aparece só na coluna _Referência MUI_, como origem.
- Cores em **HEX + RGB(A)**. O projeto escreve `rgba(R G B / A)` (CSS Color 4, separador por espaço);
  o equivalente tradicional `rgba(R, G, B, A)` vem junto.
- Toda linha cita `arquivo:linha`.
- Nada foi arredondado nem abreviado. Onde não deu para confirmar, está marcado `⚠️ NÃO CONFIRMADO`.

## 1. Sombras — escala `shadows[0..24]`

O projeto mantém **a geometria exata do MUI** (mesmos offsets, blurs e spreads da escala Material)
mas **troca a cor**: no tema claro a base é `grey.500` (`#919EAB`), não preto.

| Fato                             | Valor                                                                   | Origem (arquivo:linha)                                                           |
| -------------------------------- | ----------------------------------------------------------------------- | -------------------------------------------------------------------------------- |
| Função geradora                  | `createShadows(colorChannel)`                                           | `frontend/src/theme/core/shadows.ts:11`                                          |
| Opacidade da camada 1 (`color1`) | `0.2`                                                                   | `frontend/src/theme/core/shadows.ts:12`                                          |
| Opacidade da camada 2 (`color2`) | `0.14`                                                                  | `frontend/src/theme/core/shadows.ts:13`                                          |
| Opacidade da camada 3 (`color3`) | `0.12`                                                                  | `frontend/src/theme/core/shadows.ts:14`                                          |
| Base de cor — **light**          | `grey['500Channel']` → `145 158 171` (`#919EAB` / `rgb(145, 158, 171)`) | `frontend/src/theme/core/shadows.ts:46`                                          |
| Base de cor — **dark**           | `common.blackChannel` → `0 0 0` (`#000000` / `rgb(0, 0, 0)`)            | `frontend/src/theme/core/shadows.ts:47`                                          |
| Registro no tema                 | `colorSchemes.light.shadows` / `colorSchemes.dark.shadows`              | `frontend/src/theme/create-theme.ts:23`; `frontend/src/theme/create-theme.ts:28` |

⚠️ Como `MuiPaper` tem `elevation: 0` por default, **a escala `shadows` quase não é usada no
produto**. Card, Dialog, Popover, Menu e Drawer usam `customShadows` (§2), não `shadows[n]`.
Usos reais de `shadows[n]` em `frontend/src/**`: `theme.shadows[8]` em
`frontend/src/modules/relatorios/views/list-view.tsx:58` e `theme.shadows[6]` em
`frontend/src/auditoria/theme/override-global-style.ts.ts:18` (este último é **código morto** —
extensão dupla `.ts.ts` e nenhum import em todo o `src/`).

(`frontend/.ds-extract/theme.json` → `computed.shadowsLight` / `computed.shadowsDark`),
gerado por `frontend/src/theme/core/shadows.ts:16-45`. **Note a ausência de espaço após as vírgulas
