## 1. Como os ícones funcionam neste sistema

| Item               | Valor                                                   | Origem                                                    |
| ------------------ | ------------------------------------------------------- | --------------------------------------------------------- |
| Biblioteca         | **Iconify** (`@iconify/react` 5.2.0)                    | `frontend/package.json`                                   |
| Componente de uso  | `<Iconify icon="colecao:nome" />`                       | `frontend/src/components/iconify/iconify.tsx:21-53`       |
| **Tamanho padrão** | **`20px`** (`width = 20`, e `height = height ?? width`) | `frontend/src/components/iconify/iconify.tsx:21,44-46`    |
| Cor                | `currentColor` — herda a cor do texto do elemento pai   | os SVG usam `fill="currentColor"`                         |
| Alinhamento        | `display: inline-flex`, `flex-shrink: 0`                | `frontend/src/components/iconify/iconify.tsx:44-47`       |
| Grade base         | **24×24** (exceto `carbon`, que é **32×32**)            | `frontend/src/components/iconify/register-icons.ts:42-43` |
| Registro offline   | `addCollection()` no primeiro render                    | `frontend/src/components/iconify/register-icons.ts:33-49` |

⚠️ **Não existe `@mui/icons-material` no projeto** (0 importações). Todo ícone é Iconify ou SVG escrito à mão no tema.

`frontend/src/components/iconify/icon-sets.ts`. Os outros **163** são buscados na internet a cada carga.

```
Icon "..." is currently loaded online, which may cause flickering effects.
To ensure a smoother experience, please register your icon collection for offline use.
```

**Efeitos práticos:** piscada ao carregar, ícone ausente sem internet e diferença visual

## 7. Como usar este pacote em outra biblioteca de UI

1. **Copie a pasta `svg/`** — são os ícones exatos que a aplicação usa hoje.
2. Todos os SVG usam `fill="currentColor"`: para colorir, basta definir `color` no elemento pai.
3. Renderize com **20×20 px** para bater com o padrão do sistema (`04-tamanhos-e-dimensoes.md`).
4. A grade nativa é 24×24 (32×32 na coleção `carbon`) — ao usar 20px há uma redução de escala,
   que é exatamente o que acontece hoje na aplicação.
5. Os 4 ícones quebrados: use os arquivos de `svg-substitutos/`.
6. `svg-tema/` são os ícones internos dos componentes (seta do seletor, marcador da caixa de seleção,
   ícones de alerta etc.) — necessários para reproduzir os componentes fielmente.
